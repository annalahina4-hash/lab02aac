«Ответы на контрольные вопросы»
1. Что такое IL и зачем он нужен между C# и машинным кодом?  - il это промежуточный язык, который понимает среда исполнения .net он помогает запускать код на любых ос и работает под разные языки программирования 
2. Почему .dll можно декомпилировать?  потому что в .dll лежит не машинных код , а IL  
3.  Какие отличия Debug и Release вы увидели в IL?  debug работает  дольше но содержит более подробных код  , а release  более оптимизирован и короче за счет того что release не использует пустые операции 
4. Почему Release обычно быстрее Debug?  потому что release больше оптимизирован  , меньше команд .
5. Почему строковый пароль в .dll нельзя считать защищённым?  потому что пароль можно посмотреть в il .
